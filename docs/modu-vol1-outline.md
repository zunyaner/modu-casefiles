# 《默读》卷一 · 何忠义案（「520」案）剧情提纲（据原著整理，供游戏改编用）

> **卷名更正**：多个来源一致显示，《默读》的分卷是 序章 → **于连（一至三十一）**（何忠义案）→ 朗读 → 亨伯特·亨伯特 → 朗读（二）→ 麦克白 → 朗读（三）→ 维尔霍文斯基 → 朗读（四）→ **埃德蒙·唐泰斯（一至四十九）**（顾钊旧案，终卷）。
> 所以何忠义案是 **卷一《于连》**（典出《红与黑》），《埃德蒙·唐泰斯》（典出《基督山伯爵》）是第五卷。用户说的是“何忠义案”，本提纲和游戏按何忠义案（卷一《于连》）来做；游戏内卷名用《于连》，只有文件名按要求保留 “艾德蒙唐泰斯 / dantes”。
> 只记录情节事实，不摘录原文。

## 一、时间线（燕城，国际会议期间单双号限行）

**5月20日（承光公馆开业暖场夜）**
- 傍晚，东区一家咖啡店里，送货少年（额角有月牙形小疤，就是何忠义）向店员打听「承光公馆」在哪，借口说那边招快递员。费渡在场，戳穿了这个借口，少年跑了。
- 费渡被张东来（富二代朋友、张局的侄子）拉去承光公馆捧场，十二点准时离开，回去路上听着《红与黑》有声书睡着了。一辆开远光灯的车跟他们擦身而过，拐进了西区。
- 何忠义：约 20:50 在公馆外一条石子小路上徘徊抽烟，怀里抱着牛皮纸袋，接了一个电话后离开（被一个伪装成鸟窝的隐蔽摄像头拍到）；约 21:00/21:10 在「南平大道东」站上了 34 路，二十多分钟后在「文昌路口」下车，之后监控里就没有他了。
- 约 21:15，花市西区一片荒地上有争吵声（附近居民于磊等人听见），室友马小伟当时也在场：他偷了何忠义的新手机，拿去换了毒品。那片荒地就是贩毒团伙交易用的「金三角空地」，花市区分局刑侦支队长黄敬廉一伙当晚在那儿。
- 约 21:50，何忠义手机收到一个黑号发来的短信：「结账地点改在金三角空地，五月二十日」。
- 法医推断死亡时间在 21:00–22:00。死因：后脑先被钝器打晕，再被软布带勒死。

**5月21日**
- 凌晨，尸体在西区群租房后面的空地被发现，额头上贴着一张撕下来的纸条，写着「钱」字；手机不见了，钱包被掏空。几个小混混拍了照片发到网上，分局删帖，事情反而闹大。
- 市局张局（张春久）派骆闻舟去“技术指导”，真正的任务是抓花市区分局局长王洪亮的把柄。同一天早上，费渡给陶然送了一束花。
- 现场：王洪亮一口咬定“熟人作案”；分局新人肖海洋汇报时说“不能排除这里不是第一现场”，被王洪亮训了。陶然注意到死者的鞋很干净。
- 下午：马小伟偷五块钱引起群殴，人被带回分局。于磊作证说九点多听见两个外地口音的男人吵架。马小伟审讯时说漏了嘴，准确说出了“九点一刻”，之后只翻来覆去讲他下楼一个人都没看见。
- 晚上：费渡在分局门口等陶然，跟骆闻舟又互相呛了一轮。车上，陶然包里的现场照片滑了出来，费渡从照片推断：外衣吊牌没剪（衣服是想穿一次再退）、左脚鞋磨得厉害（鞋是借的）、他是去见一个敬重的人。最后他看到死者证件照上的月牙疤，认出了这个人。

**5月22日**
- 分局以死者手机在马小伟身上为由拘了马小伟（他身份证是改过的，其实才十六岁）。骆闻舟当着王洪亮的面装客气。
- 骆闻舟坐上黑车司机陈振的车，拿到一份匿名举报：王洪亮一伙给贩毒网络提供保护。
- 陶然和肖海洋见了何忠义的同乡「赵玉龙」：鞋是他借的；何忠义说要去“承光公馆”见人；那部白色新手机据说是“挨了打之后人家赔礼送的”。顺着配送线路查到一段冲突监控，打人的是张东来。
- 费渡托人拿到承光公馆外围的监控，找到鸟窝摄像头下那个徘徊的人影，赶在暴雨前把垃圾桶上的几个烟蒂捡走了。
- 张东来被带回市局。费渡接受询问时分析张东来没胆子杀人，给了骆闻舟一个 U 盘，还说了一句：这案子一开始就被人盯上了，“是巧合还是有人在整你们？”骆闻舟提了一句：七年整了。
- 张局避嫌，副局长陆有良接手。骆闻舟跟陆局说了自己的判断：这是两个案子缠在了一起。他决定先把张东来当重点嫌疑人挂着，让王洪亮以为市局的视线已经离开了西区。
- 夜里：烟蒂寄到了骆闻舟家（附言“顺便”）。骆、陶从鸟窝摄像头一路查到公交站，确认上 34 路的就是何忠义。骆闻舟把陶然一段“假设”对话录了音发给费渡（费渡当时在白老师那里做心理咨询）。

**5月23日**
- 张婷（张东来的妹妹）带着刘律师来，费渡陪着。张婷说何忠义曾在她公司楼下拦住她，打听一个叫「冯年哥」的人；张东来打人那天是她男朋友赵浩昌开车来接的。
- 骆闻舟跟费渡谈起七年前费渡母亲的案子：他把当年的证据结论完整说了一遍。费渡说不接受这个结论，但承认“你的忠告未必没有道理”。
- 何忠义的母亲王秀娟到了燕城（尿毒症，常年透析）。分局把「520」案移交市局。陶然查到 34 路的终点是文昌路口；法医报告到了；那条“结账地点”的短信也被发现。骆闻舟问陈振知不知道「金三角空地」。
- 晚上，赵浩昌到费氏谈业务。费渡随口问他老家哪里，他卡了一下。

**5月24日（周五，限行最后一天）**
- 陈振姐姐陈媛的相册里有一张照片，带出了她的大学同学「崔颖」。
- 张东来以“证据不足”被释放，细节一概保密，其实是放出去钓鱼。王秀娟拦住张东来那帮人问“谁害死了我儿子”，费渡留下来陪她。
- 何忠义的账本里，“钱”字的写法跟纸条上一模一样，那张纸条是死者自己写的；账上还有一笔来路不明的十万元借款。
- 陶然去相亲。费渡对陶然改了称呼，叫他“哥”。骆闻舟把费渡留下在食堂吃饭，剥了一盘虾。费渡分析：凶手是死者来燕城之前就认识的人，可能改过名。
- 同一晚，刘律师在张东来车后座的缝里发现一条银灰色条纹领带，偷偷带走交给了警方。
- 陈振打来求救电话。骆闻舟独闯鸿福大观，前台塞给他纸条，吴雪春（Linda）冒险帮他。他在储物间中了黄敬廉的埋伏，带伤跳窗逃出，被摩托车追。费渡开车冲进来救人（他晕血），对方开了枪。被堵住的时候，费渡问会不会算防卫过当，骆闻舟按住了他扣在换挡拨片上的手。增援赶到。陈振已经死了，死于毒品过量。
- 分局有人收到短信要“处理掉马小伟”，肖海洋把马小伟带出来送到了市局。马小伟当着王秀娟的面跪下说“是我”：他以为何忠义是因为他卖手机才出的事。肖海洋交代了陈媛案的疑点、两千块封口费，还说自己用 GPS 监视同事，查到 5 月 20 日黄敬廉一伙就在“那个地方”。
- 陶然坐出租车听有声书，结尾分享赏析的领读员 ID 叫「朗诵者」，他心里一震（后续伏笔）。
- 领带上有张东来的指纹，勒痕吻合，沾着死者的血。费渡推断：当晚接张东来出来的人里，赵浩昌的律所在**文昌路 103 号**。王秀娟从市局失踪了，之前接了一个怪声音打来的电话。费渡推断她会被带去花市东区，靠的是直觉。

**5月25日（凌晨 → 周六）**
- 东区“天幕”大屏开始闭幕式预演，五分钟倒计时。费渡买下天幕的播放权，先打出何忠义的照片，再亲自出镜，拿自己母亲的事跟王秀娟说话，屏幕角上同时打出租车车牌。
- 双子大楼 A 座楼顶的护栏被人弄松了，王秀娟往回缩的时候护栏断了。骆闻舟扑上去抓住了她的脚踝，刚缝好的背伤又裂开。
- 有人举报公园里有可疑车辆，骆闻舟判断是假的，下令恢复备用电源、打开全部监控。赵浩昌从 B 座绕进空中走廊时被拍到，当场被抓，兜里有沾着铁屑和油漆的手套。
- 小花园里，骆闻舟说起当年查过费渡父亲、知道他一直盯着父亲行程的事，然后向他道歉；话没说完，发着高烧晕倒了。
- 白天：赵浩昌只承认弄松护栏，说是“恶作剧”，不在场证明是在律所加班。领带上的血经 DNA 确认是何忠义的。王秀娟想起来，这个人像村里的「赵丰年」，也就是“冯年哥”。赵家当年一场大火烧死了一家五口，被认定是村里一个傻子玩火引起的，当时只有赵丰年不在家。
- 骆、陶在燕西政法找到崔颖，拿到陈媛留下的 U 盘，视频里有王洪亮和黄敬廉给女孩注射毒品。崔颖曾把这件事告诉过赵浩昌，赵浩昌还跟她开过一个“玩笑”：杀了人就扔到毒品交易点，没人敢查。
- 郎乔搜赵浩昌的家，什么都没找到；后来查到郊区「风情酒庄」12 号的地下室：一排排玻璃罐里装着他的“纪念品”，有傻子那只单只套袖（标签写着「解脱」）、何忠义的旧手机、费渡丢的钢笔，中间一盏做成“着火的树”形状的落地灯。
- 审讯：骆闻舟先拿他的出身激怒他，再提崔颖和陈媛，最后出示 34 路的监控。赵浩昌反咬一口：“下车之后的事你们不知道。”骆闻舟这时才说出酒庄地下室和旧手机。赵浩昌失控，喊出了“张东来的指纹清清楚楚地印在领带上”，这件事只有警方知道。接着他改口称“正当防卫”：说何忠义吸毒、贩毒、敲诈他十万，还拿出自己在金三角空地装的针孔摄像头当证据。骆闻舟反驳了两点：尸检显示何忠义没碰过毒品，手机是被室友偷走的；摄像头为什么偏偏装在何忠义窗外？
- 费渡推断：赵浩昌把窗外拍到的录像匿名寄给了王洪亮一伙，想借刀杀人；结果黄敬廉查内鬼，查到身上藏着摄像头的陈媛，她成了何忠义的“替死鬼”。黄敬廉看到证据后，把王洪亮的事都交代了。
- 卷末留下的悬念：那条“结账地点改在金三角空地”的短信到底是谁发的？

**朗读（卷一尾声）**
- 周一，何忠义的遗体交还家属。“赵玉龙”、马小伟、张东来都到了，张东来别扭地道了个歉。
- 王秀娟问：“我家忠义有没有干过坏事？”费渡回答：“没有。”她又问：“我教他待人要好、做人实在，是教错了吗？”没人回答得了。
- 回溯何忠义这一路：他当年借了“丰年哥”的钱给母亲治病，一直守着约定不对外提这个人；攒到两万块想先还上，联系不上人，只好去找张婷打听，结果挨了一顿打，而那个人就站在旁边，当作不认识他；那天他打听到承光公馆，是想去还钱。
- 经贸中心借这次热度发起了一个乡村失独老人基金。
- 费渡去墓园看母亲，这是第七年；骆闻舟等他走了才过去，放了一束小白菊，这时下起了雨，费渡折回来替他撑了伞。

## 二、人物与阵营
- 市局：骆闻舟（刑侦队长）、陶然（副队）、郎乔、张局（张春久，后来避嫌调岗）、陆有良（副局）、法医。
- 花市区分局：王洪亮（局长）、黄敬廉（刑侦支队长）、肖海洋（新人，暗中盯黄敬廉）。
- 证人和相关人：马小伟（室友，16 岁，吸毒，偷了手机）、于磊（保安，听见争吵）、赵玉龙（同乡、借鞋的人）、张东来、张婷、刘律师、陈振（举报人，后来遇害）、陈媛（已死，留下证据）、崔颖、吴雪春（Linda）、王秀娟（死者母亲）、白老师（费渡的心理咨询师）。
- 真凶：赵浩昌（原名赵丰年，荣顺律所二级合伙人，张婷的男朋友）。

## 三、几个来源说法不一或交代不清的地方（以及游戏里怎么处理）
1. **卷名**：用户写的是“卷一《艾德蒙·唐泰斯》”，但目录类来源（百度百科、tjs5、天涯书库目录）都显示卷一叫《于连》，《埃德蒙·唐泰斯》是第五卷。→ 游戏内一律用卷一《于连》，文件名按要求保留。
2. **那条短信是谁发的**：卷一没有交代，第 32 章末骆闻舟还在让人接着查；第五卷（hetushu Part5 第十一章）重提此事，暗示可能另有其人（不是赵浩昌自导自演）；十柠暄的梗概也写“有人暗示他……金三角空地很安全，可以抛尸”。→ 游戏正线保持悬而未决；白板上这一格对应的人是“身份不明者”；只在重读模式里用铅笔批注轻轻点一下，不下结论。
3. **“赵玉龙”的身份**：卷一里他是个普通的老乡证人；第五卷（Part5 第十八章）查出“赵玉龙”是冒名顶替的，真正的赵玉龙五年前就回老家了。→ 卷一正线照原样当证人处理，只在重读模式加一句“后卷另有揭晓”的批注。
4. **赵家那场大火是不是赵浩昌放的**：原著没有定论。他收着傻子的套袖，标签写“解脱”；骆闻舟的判断是“最多是见死不救”。→ 游戏不定性，审讯里只当他的谎言和破绽来用。
5. **具体在哪儿行凶**：原著只交代了文昌路口一带、他的律所附近，没有写具体地点；骆闻舟说“谁告诉你我们找不到他的踪迹了”是在诈他。→ 游戏里也不编具体的第一现场，诈供的机制照原著来。
6. **纸条**：第一章写的是“白纸”，后文技术分析说是从牛皮纸袋上撕下来的，字是死者自己写的。→ 游戏统一写成“从纸袋上撕下来的一角纸”。
7. **袋里的两万块现金**：赵浩昌说纸袋里有两万块，钱后来去了哪儿原著没交代。→ 游戏不写去向。
8. **何忠义为什么没在第一次“借刀”时出事**：费渡也说不知道。→ 游戏保留这个不确定。
9. **时间细节**：何忠义上车的时间，第 10 章写“九点左右”，第 13 章写“九点十分左右”。→ 游戏统一写约 21:10 上车。
